What to import

A regular expression on the block's id and name. Only plain structural blocks (TypeId CubeBlock) that fit in one cell are imported. Armour with a game shape joins the matching vanilla card. Other blocks are read from their model and grouped by shape, so blocks with the same shape share one card.
Blocks larger than one cell (most wings) are counted but not imported yet.

Scale and grid

A block is considered for a cell only when the model fills at least a fifth of the block's own volume (a plate: of the model's thin skin). Among those, the winner is the block whose faces best match the model's surface in the cell: the surface should lie on the block's faces, and every face the block shows should have model surface on it. Simpler blocks take near-ties. Thin bits of a neighbour poking through a grid line get no block.

Layer

The map is the selected layer seen from above: front on the right, columns numbered from the rear, rows from the -Z side (row 1 at the top). Letters are block keys (click a cell for the full name); a dot is a cell the model touches where no block fits.

Edit a cell

Click a cell on the layer map, or a block in the 3D view, to select it. Edits are kept in this browser for this model and grid settings.
No cell selected.
All blocks in use: click one for this cell, then pick its turn below.
Keyboard
Type a block's key (the letters on the map, e.g. H, SCT) to use it; Enter takes a key that is also the start of a longer one. 1 / 2 / 3 turn vertical / length / width. Delete or 0: no block; Backspace: auto. Arrows move along the layer, Page Up / Page Down change layer, Tab / Shift+Tab the next / previous cell with material. Ctrl+C picks up, Ctrl+V puts the picked-up block in the selected cell, Ctrl+Z undoes, Esc stops painting.
